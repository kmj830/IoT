# 🐶 멍메이트 (DogMate) - 반려동물 분리불안 & 이상행동 원격 케어 키트
> **프로젝트명**: **멍메이트 (DogMate)**  
> **국립금오공과대학교 컴퓨터공학전공 2026-2학기 IoT기초설계**  
> **팀원**: 김민중, 김영재  
> **하드웨어 플랫폼**: Raspberry Pi 3 Model B V1.2 + GrovePi+

## 📌 1. 프로젝트 개요 & 기획 배경
* **한 줄 요약**: 단순 영상 조회를 넘어, **복합 센싱(소음·영상·환경) 기반 이상행동 감지**, **원격 인터랙션(간식 투출·안심 음성 송출)**, **상태 피드백(재고 잔여량·환경 시각화)**을 결합한 엣지 지능형 IoT 케어 시스템
* **기존 펫캠의 한계**:
  * 시중 상용 펫캠(Furbo 등)은 25~35만 원의 고가이며, 월 8,000~15,000원의 유료 구독료를 강제함.
  * 외부 클라우드 경유로 인한 사생활(CCTV) 해킹 위험 존재.
  * 단순 '단방향 실시간 영상 조회'에 머물러 있어, 분리불안 증세(지속적 짖음, 불안 배회) 발생 시 능동적인 진정 케어가 어려움.
* **본 프로젝트의 차별점**:
  1. **이벤트 기반 능동 알림**: 짖음 소음(사운드 AI) 및 현관 배회(비전 ROI) 감지 시 웹 대시보드로 즉시 알림 전송.
  2. **양방향 원격 인터랙션**:
     * **Push-to-Talk 음성 송출**: 웹 브라우저에서 녹음한 보호자 목소리를 키트 스피커로 즉시 재생하여 안심 유도.
     * **원격 간식 디스펜서**: 웹 버튼 클릭을 통해 서보모터(SG-90)로 간식 1회 물리 투출.
  3. **실시간 재고 & 환경 모니터링**:
     * 초음파 센서로 간식통 잔여량(%) 자동 산출.
     * 온습도 및 조도 센서를 활용하여 어두워지면 LED 안심 조명 자동 점등.
  4. **엣지 리소스 최적화 (RPi 3B 맞춤형)**: 1GB RAM 환경에 맞추어 상시 고부하 추론을 방지하고, **데시벨 1차 트리거 ➔ AI 2차 검증**의 2단계 파이프라인 적용.

## 🛠️ 2. 사용 기술 스택 (Tech Stack)

### ① 하드웨어 (보유 키트 100% 반영)
* **메인 컨트롤러**: Raspberry Pi 3 Model B V1.2 (Broadcom BCM2837 1.2GHz Quad-Core, 1GB LPDDR2 RAM)
* **센서 확장 보드**: GrovePi+ 쉴드
* **입력 센서군**:
  * **USB 마이크**: 16kHz 오디오 스트림 수집 (YAMNet AI 음향 분석용)
  * **라즈베리파이 카메라 (CSI)**: 5MP 카메라 모듈 (현장 스틸컷 캡처 및 MJPEG 스트리밍)
  * **Grove 사운드 센서**: 아날로그 소음 데시벨(dB) 측정 (1차 트리거)
  * **Grove 초음파 센서**: 간식통 내부 거리 측정 (잔여량 % 환산)
  * **Grove 온습도 센서**: 실내 온도 및 습도 모니터링
  * **Grove 빛(조도) 센서**: 실내 밝기 측정 (야간 감지)
* **출력 액추에이터군**:
  * **SG-90 마이크로 서보모터**: 간식 1회 회전 투출 기구 구동
  * **USB 스피커 (또는 소형 스피커)**: 보호자 음성 메시지(WAV) 재생
  * **Grove LED 모듈**: 야간 안심 조명 및 시스템 상태 표시등
  * **Grove 부저**: 간식 투출 알림 비프음

### ② 소프트웨어 & 프레임워크
* **운영체제**: Raspberry Pi OS (Linux 32-bit / 64-bit Lite)
* **개발 언어**: Python 3.10+
* **임베디드 제어**: `grovepi`, `RPi.GPIO`
* **웹 백엔드**: Flask (REST API, MJPEG 영상 스트리밍, 음성 파일 업로드 라우팅)
* **프론트엔드**: HTML5, CSS3, Vanilla JavaScript, MediaRecorder API (Push-to-Talk)
* **오디오 처리**: `sounddevice`, `scipy`, `pygame.mixer` (비동기 음성 재생)

## 🧠 3. 사용할 AI 모델 (AI Models)

라즈베리파이 3B(1GB RAM)의 하드웨어 리소스를 고려하여 **초경량 엣지 AI 런타임(`tflite-runtime`)**을 채택합니다.

| 분류 | 모델명 | 용량 / 형식 | 역할 및 동작 방식 |
| :--- | :--- | :--- | :--- |
| **오디오 AI** | **Google YAMNet-TFLite** | **3.8MB** (`.tflite`) | **실제 짖는 소리 감별**<br>AudioSet 기반 521개 클래스 중 `Bark`(71번), `Dog`(70번), `Howl`(73번) 판별 (공사/생활 소음 필터링) |
| **컴퓨터 비전** | **YOLOv8n-TFLite**<br>*(또는 OpenCV MOG2+ROI)* | **6.5MB** (`.tflite`) | **현관문 관심 구역(ROI) 반려견 체류 감지**<br>COCO 데이터셋 Class 16 (`Dog`) 검출 |

### 🚀 엣지 리소스 최적화 전략 (Event-Driven Pipeline)
라즈베리파이 3B에서 비전 AI를 상시 30FPS로 돌리면 발열과 메모리 부족이 발생합니다. 따라서 **"2단계 이벤트 트리거"** 구조로 동작합니다:
1. **평상시**: Grove 사운드센서와 경량 모션 감지만 백그라운드에서 최소 부하로 감시.
2. **이벤트 발생 시**: 기준 데시벨(70dB) 초과 시에만 ➔ **YAMNet AI(오디오) + 카메라 스냅샷(비전)**을 1회 즉시 호출(0.05초)하여 정밀 검증.

## ⚙️ 4. 핵심 시스템 파이프라인 (System Pipeline)

1. **[1단계: 상시 대기 & 1차 필터링]**
   * 사운드 센서로 실내 데시벨 상시 측정 (70dB 초과 시 2단계 진입)
   * 조도 센서 측정값에 따라 어두워지면 LED 안심 조명 자동 점등
2. **[2단계: Edge AI 정밀 검증]**
   * USB 마이크로 0.975초 오디오 수집 ➔ YAMNet TFLite 추론
   * `Bark`/`Howl` 확률이 0.35 이상일 경우 '이상 행동' 확정 및 카메라 스냅샷 캡처
3. **[3단계: 웹 알림 & 원격 인터랙션]**
   * 보호자 웹 대시보드로 경보 푸시 알림 및 스틸컷 전송
   * **음성 전달**: 웹에서 마이크 버튼을 누르고 말하면(`MediaRecorder`), 음성 파일(WAV)이 라즈베리파이로 전송되어 스피커로 즉시 출력 (`pygame.mixer`)
   * **간식 투출**: 웹 [간식 주기] 클릭 시 ➔ 서보모터 180도 회전 + 부저음 1회
4. **[4단계: 재고 및 환경 피드백]**
   * 초음파 센서로 간식 잔여 높이 측정 ➔ 대시보드 게이지(%) 실시간 갱신
   * 온습도 센서 측정값 실시간 대시보드 업데이트

## 🎯 5. 데모 시연 계획 & 기대 평가 포인트

### 100% 성공 보장형 데모 시나리오 (발표 40점 만점 전략)
1. **짖음 감지 시연**: 발표자가 라즈베리파이 근처에서 큰 소리/박수를 치면 ➔ 공사 소음으로 인식되어 무시됨. 스마트폰으로 강아지 짖는 소리를 들려주면 ➔ **0.1초 만에 웹 화면에 "🚨 짖음 감지!" 경보 배너와 사진 팝업**.
2. **Push-to-Talk 시연**: 발표자 스마트폰 웹에서 마이크 버튼 누르고 *"뽀삐야~"* 녹음 전송 ➔ 키트 스피커에서 발표자 목소리 즉시 재생.
3. **원격 간식 투출**: 웹 화면의 [간식 주기] 버튼 터치 ➔ 서보모터가 돌면서 간식이 툭 떨어짐.
4. **센서 잔여량 피드백**: 초음파 센서 앞에 손을 대어 간식통 높이를 바꾸면 ➔ 웹 대시보드의 간식 잔여량 게이지가 즉시 연동되어 변함.

### 심사위원(교수님) 평가 어필 포인트
* **창의성**: 단순 펫캠을 넘어 **Edge AI(TFLite) + 양방향 Push-to-Talk + 물리 간식 투출**이 결합된 폐루프(Closed Loop) 상호작용 시스템.
* **유용성 & 경제성**: 30만 원 상당의 상용 기기와 월 구독료를 **실습 키트와 오픈소스 경량 AI로 0원에 완벽 대체**.
* **기술적 완성도**: 라즈베리파이 3B(1GB RAM)의 한계를 공학적으로 극복한 **2단계 이벤트 트리거 파이프라인**.

### 🔬 논문별 세부 분석 및 시스템 설계 반영

#### 📌 논문 1: 보호자 음성의 분리불안 완화 효과 실증
* **출처**: Shin, N. Y., & Shin, N. S. (2016). *Journal of Veterinary Science*, 17(2), 153–159.
* **연구 내용**: 분리불안을 겪는 반려견 28마리를 대상으로 낯선 환경 격리 시 보호자 체취 또는 **녹음된 보호자 음성(Auditory stimulation)**을 들려준 후 타액 내 코르티솔(Salivary Cortisol) 수치 변화 측정.
* **핵심 결론**: 통제군 대비 보호자의 목소리를 들려준 그룹에서 **격리 초기 코르티솔 비율 상승이 유의미하게 억제**됨을 규명.
* **프로젝트 반영**: 단순 기계음이 아닌 보호자의 실제 목소리를 스피커로 들려주어 분리불안 스트레스 반응을 즉각 경감시키는 **Push-to-Talk 음성 송출 파이프라인의 학술적 근거**.

#### 📌 논문 2: 분리불안 행동학적 특징 및 행동 수정 기법
* **출처**: Ogata, N. (2016). *Journal of Veterinary Behavior: Clinical Applications and Research*, 16, 28–35.
* **연구 내용**: 분리불안의 병인, 행동 특성(발성, 탈출 시도, 배회, 파괴 행동), 환경적·행동수정 치료(Behavior Modification) 40년간 연구 진전 집대성.
* **핵심 결론**: 보호자 외출 직후 수 분 이내에 **출입구(문) 근처에서의 배회/서성임(Pacing/Gazing)과 탈출 시도 행동이 가장 빈번**하며, 불안 상태를 긍정 정서로 전환하는 **음식/간식을 활용한 역조건 형성(Counterconditioning)**이 필수적임.
* **프로젝트 반영**: 단순 방 전체 감지가 아닌 **현관문 관심 구역(ROI) 체류 알고리즘 도입 근거** 및 **원격 간식 디스펜서 기능의 치료학적 당위성 확보**.

#### 📌 논문 3: 상황별 강아지 짖음 소리의 음향학적 차이
* **출처**: Maros, K., Pongrácz, P., Bárdos, G., & Miklósi, Á. (2008). *Applied Animal Behaviour Science*, 114(1-2), 159–167.
* **연구 내용**: 고립 상황(Left alone)과 낯선 침입자 경계 시(Stranger at the gate) 반려견 짖음 소리의 심박수(HR) 반응 및 음향 스펙트럼 차이 분석.
* **핵심 결론**: 개는 고립 상황에서 침입자 경계 상황과 **확연히 다른 음향학적 특성(음고 Pitch, 음조 지속 시간, 주파수 분포)**을 가진 발성을 냄.
* **프로젝트 반영**: 단순 데시벨(dB) 측정을 넘어선 **오디오 AI(YAMNet) 적용의 기술적 명분**. 일상 생활 소음이나 외부 침입 경계음과 고립 발성(Distress Barking)을 구분하는 2-Step 하이브리드 파이프라인의 필요성을 강력 변호.

  * ➔ *"Applied Animal Behaviour Science(Maros et al., 2008) 논문에 따르면, 고립/분리 상태의 발성은 일반 경계 짖음이나 충격음과 주파수 및 음향 구조가 다릅니다. 박수나 문 닫히는 소리와 같은 오작동(False Alarm)을 방지하기 위해 데시벨 1차 트리거 후 오디오 분류 AI를 거치도록 고도화했습니다."*
